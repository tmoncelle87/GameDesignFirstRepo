# Cyberpunk 2D Autorunner

This is a Geometry Dash-style 2D autorunner we're building for our Game Design and Development class. 

## What we've built so far:
* **The Look:** A custom pixel-art night cityscape background to match our cyberpunk theme.
* **Menus & Screens:** Fully working Main Menu, Options, Game Screen, and a Shop.
* **UI & Navigation:** Smooth button navigation and in-scene toggles. The shop screen is set up with a functional back button and is ready for characters to be added.

## Built With:
* **Unity 6.3** (Version 6.000.3.22f1 LTS — stick to this exact version if you're pulling from our repo!)
* **GitHub** for version control
